# Stock Price Prediction

A machine learning project that collects stock data, prepares the data, trains a model, and displays stock predictions using Streamlit.

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Yahoo Finance

## Project Files

- `app.py` - Streamlit application
- `data_collection.py` - Collects stock data
- `prepare_data.py` - Prepares the data
- `train_model.py` - Trains the machine learning model
- `data/` - Contains stock datasets
- `model/` - Contains the trained model
